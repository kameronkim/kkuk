**꾹 눌러, 더 작게.**

파일이나 폴더를 7z 압축 파일로 만드는 macOS 앱입니다. 입력 크기와 메모리 여유에 맞춰 고압축 프리셋을 자동으로 선택하므로, 별도 설정이 필요 없습니다.

[English guide](README.md)

## 시작하기

macOS 26 이상인 Apple Silicon Mac에서 `Kkuk.app`을 실행하세요. 별도의 7-Zip 설치는 필요하지 않습니다. 앱은 macOS 언어 설정에 따라 영문·한국어로 표시됩니다.

1. 파일이나 폴더 하나를 창에 놓거나, 클릭해서 선택합니다.
2. **압축하기**를 선택합니다.
3. 완료되면 **Finder에서 보기**로 결과를 확인합니다.

Finder에서 파일이나 폴더를 우클릭하고 **꾹으로 압축**을 선택하면 작은 진행 창에서 바로 압축합니다.

## 동작 방식

- 압축률을 우선합니다. 입력에 따라 시간이 오래 걸리거나 용량이 거의 줄지 않을 수 있습니다.
- 압축 파일을 검사하고 원본 변경 여부를 확인한 뒤 결과를 확정합니다.

압축만 지원하며, 압축 해제·암호화·분할 압축은 제공하지 않습니다.
